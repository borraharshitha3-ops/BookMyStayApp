# BookMyStayApp

## Description
BookMyStayApp is a hotel booking application developed using Java. It allows users to search hotels, book rooms, and receive booking confirmations.

## Features
- User Registration & Login
- Hotel Search
- Room Booking
- Booking Confirmation
- User-Friendly Interface

## Technologies Used
- Java
- IntelliJ IDEA
- Git & GitHub

## How to Run
1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Build and run the application.
